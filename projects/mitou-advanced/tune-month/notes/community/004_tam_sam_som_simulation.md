## 1. TAM / SAM / SOM 推定

### 定義

- **TAM**（Total Addressable Market）: 理論上の最大市場
- **SAM**（Serviceable Addressable Market）: TUNEが到達可能な市場
- **SOM**（Serviceable Obtainable Market）: 初年度に現実的に獲得できる規模

---

### TUNE-month（5〜10万円/人・月）

| レイヤー | 算出根拠 | 人数 | 金額（年間） |
|---------|---------|------|------------|
| **TAM** | 経営者360万人 × メンタルヘルス関心率86.9% ≒ 313万人のうち、自己投資に月5万円以上使える層を10%と仮定 | 31万人 | 31万 × 60万円 = **1,860億円** |
| **SAM** | 上記のうち「脳波×パフォーマンス最適化」というコンセプトに関心を持つ層を3%と仮定 | 約9,400人 | 9,400 × 60万円 = **56億円** |

**前提**: 単価は中間値の5万円/月×12ヶ月=60万円/年で計算

## 2. 収支シミュレーション（初年度）

### 売上シナリオ

| サービス | 悲観 | 中間 | 楽観 |
|---------|------|------|------|
| TUNE-month | 10名 × 60万 = 600万 | 25名 × 60万 = 1,500万 | 50名 × 60万 = 3,000万 |
| デバイス販売 | 200台 × 4万 = 800万 | 500台 × 4万 = 2,000万 | 1,000台 × 4万 = 4,000万 |
| サブスク | 150人 × 1.2万 = 180万 | 400人 × 1.2万 = 480万 | 800人 × 1.2万 = 960万 |
| コミュニティ | 30人 × 3.6万 = 108万 | 100人 × 3.6万 = 360万 | 300人 × 3.6万 = 1,080万 |
| イベント | 月1回 = 90万 | 月2回 = 180万 | 月4回 = 360万 |
| 据え置き | 2箇所 = 180万 | 5箇所 = 450万 | 10箇所 = 900万 |
| **合計** | **1,958万円** | **4,970万円** | **1億300万円** |

### コスト構造（概算）

| 項目 | 月額 | 年額 | 備考 |
|------|------|------|------|
| デバイス原価 | 変動 | 売上の40〜50% | 4万円販売なら原価1.6〜2万円 |
| 講師・専門家謝礼 | 10〜30万 | 120〜360万 | イベント・コミュニティ向け |
| アプリ開発・保守 | 20〜50万 | 240〜600万 | PEAKS契約180万+保守 |
| プラットフォーム費 | 3〜5万 | 36〜60万 | コミュニティ/配信ツール |
| マーケティング | 10〜30万 | 120〜360万 | SNS広告・イベント告知 |
| その他固定費 | 10〜20万 | 120〜240万 | — |
| **合計（変動費除く）** | **53〜135万** | **636〜1,620万** | — |

### 損益シナリオ

| シナリオ | 売上 | コスト（固定+変動） | 営業利益 |
|---------|------|-------------------|---------|
| **悲観** | 1,958万 | 固定636万 + デバイス原価400万 = 1,036万 | **+922万** |
| **中間** | 4,970万 | 固定1,000万 + デバイス原価1,000万 = 2,000万 | **+2,970万** |
| **楽観** | 1億300万 | 固定1,620万 + デバイス原価2,000万 = 3,620万 | **+6,680万** |

## 3. 損益分岐点の目安

最低限の固定費（月53万円＝年636万円）を賄うために必要な組み合わせ例：

| パターン | 内容 | 年間売上 |
|---------|------|---------|
| A | TUNE-month 10名 + デバイス100台 | 600万 + 400万 = 1,000万 |
| B | TUNE-month 5名 + デバイス150台 + サブスク100人 | 300万 + 600万 + 120万 = 1,020万 |
| C | デバイス200台 + サブスク200人 + コミュニティ50人 | 800万 + 240万 + 180万 = 1,220万 |

**→ TUNE-month 10名 + デバイス月8〜9台程度で固定費は回収可能**

### ファネル構造

```
[認知]  据え置き体験 / イベント / SNS
  ↓  転換率 10〜20%
[試用]  体験会・無料イベント参加
  ↓  転換率 20〜30%
[購入]  デバイス販売
  ↓  転換率 60〜80%
[継続]  サブスク（アプリ）
  ↓  転換率 10〜20%
[深化]  TUNE-month / コミュニティ
```

## 5. 留意事項・リスク

| リスク | 対策 |
|--------|------|
| デバイス初期在庫リスク | 受注生産 or 小ロット生産から開始 |
| TUNE-month の顧客獲得コスト | 経営者ネットワーク・紹介制度を活用 |
| サブスク解約率 | 月次レポート等で価値を実感させる仕組み |
| 薬機法・医療機器規制 | 「治療」ではなく「セルフケア・ウェルネス」のポジショニングを徹底 |
| 競合参入 | 脳波×コミュニティの先行者優位を確立 |
