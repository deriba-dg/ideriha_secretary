# TUNE 市場調査レポート

最終更新: 2026-04-01

> 4つのターゲットセグメントについて市場規模・競合・ターゲット人口を調査した結果。
> TUNE-month / デバイス販売 / サブスク を主力サービスとした TAM/SAM/SOM 推定の基礎資料。

---

## 1. マインドフルネス・瞑想市場

### 市場規模

| 指標 | 数値 | 出典 |
|------|------|------|
| 国内市場規模 | 約440億円（2020年） | ラッセル社調査 |
| 潜在市場 | 約2,500億円 | 同上（やや過大との指摘あり） |
| 月1回以上の実践者 | 約193万人 | 同上 |
| 潜在層 | 約935万人 | 同上 |
| グローバル市場 | 75〜96億ドル（2025年）→ 170〜275億ドル（2030-32年） | CAGR 13〜23% |

### 実践者の特徴

- 31%が毎日実践
- 夜寝る前(48.8%)、朝起床後(35.8%)が主なタイミング

### 主要競合

| サービス | 月額 | 主な実績 |
|---------|------|---------|
| **Upmind** | 1,650円（年6,600円） | 累計150万DL超、グッドデザイン賞 |
| **MELON** | 4,950円 | 参加者累計30万人超、継続率90%以上 |
| **RussellME** | 300円 | 小室哲哉氏ら監修 |
| **muon** | 500円 | 「寝たまんまヨガ」累計200万DL |
| **Relook** | 2,200円（年6,900円） | 国内人気上位 |
| **Calm** | — | グローバル1億DL超、2020年日本上陸 |
| **Headspace** | — | グローバル7,000万DL超、日本語未対応 |

### TUNEへの示唆

- 瞑想アプリは月500〜5,000円の価格帯に集中。TUNEのサブスク1,000円/月は中間で妥当
- **脳波データ連動**という差別化要素は既存アプリにはない
- 193万人の実践者のうち、デバイス+データに価値を感じる層がターゲット

## 2. 経営者・ハイパフォーマー市場

### 市場規模

| 指標 | 数値 | 出典 |
|------|------|------|
| 日本の社長数 | 約360万人 | 帝国データバンク |
| 社長平均年齢 | 60.7歳（50歳以上が81.7%） | 同上（2024年） |
| 経営者の病気・死亡による倒産 | 316件（2024年、過去最多） | 同上 |
| 国内ウェルネス市場 | 約45兆円 | Global Wellness Institute |
| コーチング市場 | 約300億円（2019年、米国の約1/50） | Ecole |
| グローバルExecコーチング市場 | 948億ドル（2024年）、CAGR 9.24% | — |

### 経営者のメンタルヘルス意識

- 86.9%が「メンタルヘルスを大切にすることは経営的に有益」と回答
- 71.4%が「自分で管理すべき問題」→ **支援を求めることへの心理的障壁が高い**
- 「心の病」増加傾向と回答した企業が39.2%で高水準継続

### エグゼクティブ向けサービス事例

- **プレミアム人間ドック**: 入会金・年会費含め200万円超のものも
- **ウェルビーイングリトリート**: BE HERE NOW（鎌倉）等、オーダーメイド型で個別見積
- **コーチング**: 月額5万〜30万円。経験者の43%が「投資額の7倍以上の価値」と評価

### TUNEへの示唆

- 経営者はニーズが高い(86.9%)が自ら助けを求めにくい → **データに基づく客観的フィードバック**が刺さりやすい
- TUNE-month（5〜10万円）はコーチング価格帯（5〜30万円/月）の下限で参入しやすい
- エグゼクティブ向けイベント（1万円/人）は、プレミアム人間ドック層と比べると非常にリーズナブル
- **「科学的な脳の可視化」がブランディングの鍵**。単なるウェルネスではなく、エビデンスベースを打ち出す

## 4. メンタルヘルス（セルフケア・デジタルヘルス）市場

### 市場規模

| 指標 | 数値 | 出典 |
|------|------|------|
| 国内メンタルヘルス市場 | 約265億ドル（約3兆円、2024年）→ 376億ドル（2034年） | IMARC Group |
| CAGR | 3.6%（全体）/ 7.5%（デジタル領域） | — |
| 精神疾患患者数 | 約419万人（2017年） | 厚労省患者調査 |
| うつ病・うつ状態の割合 | コロナ後に7.9%→17.3%へ倍増 | OECD |
| 未通院の精神疾患推定 | 約950万人 | HGPI |
| 精神障害の労災請求 | 2,051件（2020年）→ 3,780件（2024年） | 厚労省 |
| グローバルNF市場 | 13〜14億ドル（2025年）→ 23億ドル（2032年）、CAGR約7% | Coherent MI |

### 主要アプリ

| サービス | 月額 | 実績 |
|---------|------|------|
| **Awarefy** | 1,200円（年7,200円） | 累計90万DL、2024年シリーズA約4億円調達 |
| **emol** | 無料〜490円 | 約40万DL、2025年シリーズA調達 |
| **cotree** | 1回5,000円〜 | 会員約3万名、相談実績10万件超 |

### 法人市場の追い風

- 2015年: 50人以上の事業場でストレスチェック義務化
- **2028年まで**: 全事業場（50人未満含む）へ拡大予定
- 全事業場の95.9%が小規模事業場 → 外部委託需要の急拡大

### ニューロフィードバック市場の特徴

- ADHD（シェア約32%）、不安障害、うつへの応用が主
- ウェアラブル・在宅デバイスが売上の約31%
- セッションの37%が遠隔実施
- AI統合を進めるプロバイダーが55%

### TUNEへの示唆

- 未通院950万人は巨大な潜在市場。ただし「治療」ではなく「セルフケア」としてのポジショニングが重要
- Awarefy（90万DL、月1,200円）はアプリ単体。**脳波デバイス連動**で差別化可能
- 2028年ストレスチェック全事業場義務化は法人向け展開の大きな追い風
- NF市場で在宅デバイスが31%→ TUNE の在宅デバイス路線は市場トレンドに合致
